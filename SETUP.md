# MSR Tax and Insurance - React Setup Guide

## Quick Start

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Copy Assets**
   - Copy `logo.jpeg` from `msr-tax-insurance/assets/images/` to `msr-tax-insurance-react/public/assets/images/`
   - Copy `hero_section.webp` from `msr-tax-insurance/assets/images/` to `msr-tax-insurance-react/public/assets/images/`

3. **Start Development Server**
   ```bash
   npm run dev
   ```

## What's Been Converted

✅ All HTML pages → React components
✅ Navigation system → React Router
✅ JavaScript modules → React hooks
✅ CSS files → Preserved (global CSS)
✅ All functionality preserved:
   - Phone links
   - vCard generation
   - Scroll animations
   - Service ticker
   - Form validation
   - Mobile menu

## Project Structure

- `src/components/` - Reusable React components
- `src/pages/` - Page components
- `src/hooks/` - Custom React hooks
- `src/utils/` - Utility functions
- `public/assets/` - Static assets (images)
